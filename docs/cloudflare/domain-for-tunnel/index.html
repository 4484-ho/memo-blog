Cloudflare Tunnel 用ドメイン取得の記録

ローカルで開発している個人開発アプリ（Laskflow など）を、手軽に、かつセキュアに外部公開したい。 そう考えたときに真っ先に候補に挙がるのが Cloudflare Tunnel です。

Cloudflare Tunnel を運用するには、DNS の名前解決を行うための 独自ドメインが必須 です。 ここでは、インフラのランニングコストを極限まで抑えつつ、フリーランス（Tech PdM / EM）としての「ビジネスの看板」としても通用するドメインを決定・取得するまでの思考プロセスをまとめます。

1. どこでドメインを取得するか（Cloudflare vs AWS Route 53）​

まずは「どこでドメインを買うか」の選定からスタートしました。候補に挙がったのは、使い慣れている AWS の Route 53 と、トンネル運用元である Cloudflare Registrar です。

比較した結果、Cloudflare での直接取得を選びました。

比較項目Cloudflare RegistrarAWS Route 53
価格（.com）最安（原価・卸売価格） / 年間約 10 ドル標準的 / 年間約 14〜15 ドル
DNS 管理費無料有料（1 ホストゾーンあたり月 0.50 ドル＋クエリ従量）
Tunnel 連携最高（DNS レコードが自動連携される）普通（手動で CNAME を登録する必要あり）

Cloudflare を選んだ決め手​

Route 53 はドメイン維持費とは別に、Hosted Zone ごとに毎月 0.50 ドルの固定費 がかかります。「個人開発の固定費は極力削る」という方針において、手数料・上乗せ料金・ DNS 管理費が一切なし（原価提供）の Cloudflare は圧倒的に魅力的でした。

2. トップレベルドメイン（TLD）の比較と罠​

次に、末尾の文字列（.com、.org、.uk など）をどうするか。ここでいくつかの発見とトレードオフがありました。

① 破格の .uk（イギリス国別ドメイン）とその罠​

Cloudflare で検索していると、.uk が年間 5 ドル前後という破格の安さで目を引きました。しかし調査したところ、英国外からの取得自体は可能であるものの、後からレジストリ（管理団体）より 英国内の連絡先住所の証明 を求められるリスク（確認に応じられないとドメイン凍結）があることが判明。長く育てるドメインとしてはリスクが高いため見送りました。

② 技術者と親和性の高い .org​

技術コミュニティやオープンソースの印象が強い .org（年間約 10 ドル）は、個人開発の検証スペース（Sandbox）として非常に知的で格好良い選択肢でした。ただ、将来的に完全な「商用サービス」としてビジネス展開や非 IT 系のクライアントワークに使う場合、一瞬「非営利団体なのかな？」と誤解される微小なリスクを考慮しました。

③ 王道にして最強の .com​

どんなクライアント（スタートアップからエンタープライズまで）を相手にしても 100% の信頼性を担保でき、価格も年間 10 ドル前後と安定している .com。最終的には、ビジネスと開発を両立させるために .com で勝負することにしました。

3. ドメイン名（文字列）の決定：個人事業主の屋号としての設計​

個人開発において、アプリ名をそのままドメインにする（例：laskflow.com）のは、開発が終わったときにつぶしが効かなくなります。 おすすめは、自分の開発環境（秘密基地）としてのベースドメインを 1 つ取得し、アプリはサブドメインで運用する 方法です。Cloudflare ならサブドメインは無限に無料で追加できます。

今回は、自身の GitHub アカウント名やハンドルネームである 4484 や hoboteru をベースに、テック系フリーランス（PdM/EM）としての専門性がひと目で伝わる組み合わせを模索しました。

決定したドメインは 4484-tech.com です。

数字の持つシャープでデジタルなガジェット感に、-tech を加えることでプロフェッショナルとしてのアイデンティティをストレートに表現。さらに王道の .com で信頼性を担保する、バランスの取れた選択になりました。

4. 今後の運用展望​

無事にドメインが確保できたので、今後はこのドメインを以下のように活用する予定です。

  • アプリ公開： laskflow.4484-tech.com（Cloudflare Tunnel 経由でローカルから安全に公開）
  • 開発検証用： dev.4484-tech.com
  • ポートフォリオ用： portfolio.4484-tech.com（職歴や実績の集約）
  • ビジネスメール： @4484-tech.com のプロフェッショナルなメールアドレス運用

年間 1,500 円前後の固定費だけで、開発インフラと個人事業主としての信頼インフラが手に入ると考えると、Cloudflare でのドメイン取得はコストパフォーマンスが非常に高い選択です。
